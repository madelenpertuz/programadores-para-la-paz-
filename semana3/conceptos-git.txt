Repositorio:
Un repositorio es un espacio donde se almacenan los archivos y el historial de cambios de un proyecto. Permite organizar el trabajo y mantener un control sobre las versiones del proyecto.

Commit:
Un commit es un registro de los cambios realizados en un proyecto. Sirve para guardar avances y poder volver a versiones anteriores si es necesario.

Push:
El comando push se utiliza para enviar los cambios del repositorio local a GitHub u otro repositorio remoto. Esto permite compartir y respaldar el trabajo realizado.
